## 合成训练的具体范围

使用完全隔离的两个人工生成视频：16 帧训练、16 帧验证，每帧 2 个已知几何颗粒。YOLO26n 以官方权重初始化，**20 轮、128 输入、batch 4、nbs 4、AMP 关闭**，固定随机种子。实际 GPU 为 NVIDIA GeForce RTX 4060 Laptop，PyTorch 2.14.0+cu130、torchvision 0.29.0+cu130、CUDA runtime 13.0。

第一帧检出 2 个候选，选择其中 1 个；在关闭检测分融合并使用明确记录的合成数据专用分数门限后，ByteTrack 在 16 帧均有检测观测。相同固定候选上的 Trackpy、历史 Kalman/Hungarian 也均有 16/16 观测。这里验证的是接口、身份管理与导出链路，不是方法优劣或 TEM 准确率。

非常短的合成训练会产生低分候选。检查发现，ByteTrack 的分数融合可能使这些几何重叠良好的框无法关联，因此配置显式关闭该选项，并保留高低分门限。合成专用门限为 low 0.05 / high 0.10 / new 0.12；正式 TEM 默认仍为 0.10 / 0.40 / 0.50。此现象不能代替真实 TEM 参数选择实验。

检查过程中修复了锁定 Ultralytics 版本的 ByteTrack 构造接口变化、Windows UTF-8 日志、晚入场目标首帧选择，以及 Windows 虚拟环境包装进程的取消问题。最终测试结果包含这些回归覆盖。

可查看 [机器可读报告](../results/verification/synthetic_smoke_report.json)、[三种关联的合成对照](../results/verification/synthetic_comparison.csv)、[合成追踪视频](../results/verification/synthetic_annotated.mp4)。这些文件都明确标注为合成检查，不放进 TEM 模型注册表。

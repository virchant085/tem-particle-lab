# 样例实测结果

输入：所给 554×554、26 帧 TEM MP4。确认的初始 ID 为 1、2、3、4、6、7。运行日期 2026-09-28，实际环境和参数保存在各结果目录。

## 主要输出

默认方案保留 131/156 个目标帧的观测（83.97%），25 个目标帧缺测或未通过质量门限。逐 ID 观测数：1→22，2→21，3→13，4→26，6→26，7→23。观测率不是准确率；通过质量检查的点仍可能认错。

配准逐步有效 24/25。某一步失效后，后续相对首帧的背景校正坐标全部置空。原始坐标仍可用，不能用部分累计值伪装完整漂移校正。原视频 hash 在处理前后保持一致。视频输出已回读为 26 帧。

## 控制实验

相同视频、相同初始点。助手目视估计 54 个参考点（6 个身份 × 9 个早期帧）；评估排除初始化帧，仅使用帧 1–8 的 48 个点。参考坐标非专家标注，且非盲评；早期仍清楚的样本存在选择偏差。数字只能诊断定位表现，不能证明后半段身份正确或算法全面最优。12 px 为探索性容差，没有物理标定含义。

| 方案 | 全视频观测率 | 早期平均中心误差 px | 12 px 内成功率 |

| selected | 84.0% | 7.07 | 87.5% |
| without_registration | 90.4% | 7.07 | 87.5% |
| raw_no_blur | 42.9% | 8.75 | 52.1% |
| without_centroid_refinement | 89.7% | 8.89 | 83.3% |
| strict_backward_4px | 73.1% | 7.06 | 85.4% |

| search_20 | 80.8% | 7.07 | 87.5% |

| lk | 60.9% | 7.81 | 85.4% |

YOLO + legacy 完整路线：未运行，因为缺少 TEM 权重与标注；legacy 四组使用同一个 Trackpy 定位器。因此这组实验隔离的是关联代价，不等于比较旧 YOLO 模型与新模型。

默认方法与 Trackpy/legacy 的早期误差约 7 px，差别不足以证明更准确。legacy_iou_area 的观测率更高，只说明持续输出更多位置，不证明身份更可靠。去掉空间去噪后的观测率明显降低，支持在此样例保留温和高斯处理；它不是对所有 TEM 视频的泛化结论。

配准开关改变局部搜索先验和校正字段。背景不一定静止，误差也会累积；当前结果不支持声称启用配准使原始坐标更准。保留可开关模块和原始坐标有利于后续实验核查。12/20/28/40 搜索范围仅为此样例的探索性敏感性检查，不是独立选参验证。

## 失败片段与人工复核

- #3 在帧 13 后对比/身份证据不足，帧 16 起进入 lost；需要在仍可辨认处添加同 ID 的人工锚点，不能靠放宽门限恢复“可信”身份。
- #2 在帧 10、13 的前后向检查不一致，后段还有低对比间隔。
- #7 帧 19–20 的低相关后恢复，需验证恢复的是原颗粒；末帧边界附近失效。
- #1 帧 22 后逐渐缺测；#4 和 #6 连续有观测也不代表人工验证全部正确。
- `review_required.csv` 给出每一处缺测的精确原因；它不是全部可能错误的穷尽清单。

本视频总共只有 26 帧，不能提供 50–200 个不同帧的标注子集。54 个目标点不是 54 帧。正式实验建议专家标注全部 26 帧中的可辨认身份，记录不可判定区间；另用更多实验视频做独立评估。当前 HOTA、IDF1、MOTA、mAP 为空，未冒充已测。

## 软件验证与复现

测试覆盖已知亚像素合成平移、低对比消失、同 ID 人工恢复、延迟初始化、配准方向、无效累计配准、缺测不造坐标、人工纠正不产生跳变速度、非法选点及数据集只读校验。测试日志见 `docs/verification.txt`。合成验证说明实现可按定义工作，不代替真实 TEM 的精度验证。

# 标注来源与适用范围

visual_reference.csv：助手在带坐标网格的原始帧上目视记录的 **54 个近似中心参考点**，涵盖前 9 帧 × 6 个已确认 ID。属于可复核的初步视觉参考，不是用户/显微专家审核的 ground truth；中心定义、投影形变及人工读图存在数像素误差。本轮开发者已看过自动结果，标注不是盲法，不可用于无偏性能排名。

比较脚本排除初始化帧 0，实际以 **48 个非初始化参考点**估计误差，容差 12 px。它只检查早段可见颗粒的粗中心位置，**不能证明后半段 ID 正确，也不能证明亚像素准确率**。没有对不可辨认的后半段强行填写身份标签。

请在本地选点工具逐帧检查：选“校正颗粒 #ID”并点击，导出选点 JSON；正式评估时应单独建立 frame,track_id,center_x,center_y,visible CSV，盲法标注，覆盖全部 26 帧及弱对比/接触段。新增视频应按实验划分训练和测试集。

HOTA、IDF1、MOTA 和 ID switches 等身份指标留空，因为当前不是完整专家身份 GT。选点锚点、训练标签、视觉参考及模型权重是四种不同的数据，不互相代替。

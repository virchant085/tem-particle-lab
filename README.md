# TEM Particle Lab · TEM 颗粒识别与追踪

给视频里的颗粒画圈，追踪它们的移动，并把不同时间的圆圈叠加到一张图里。

**第一次使用：按下面 4 步操作，先用自带样例生成一张图片。不需要写代码。**

准备一台常见的 **64 位 Windows 10 / 11 电脑**，保持联网，至少留出约 **10 GB** 空间。

> 如果这台电脑以前已经成功打开过工具，直接双击 `start_tracker.cmd`，跳到第 4 步。

## 第 1 步：下载工具

1. 打开[项目页面](https://github.com/virchant085/tem-particle-lab)。
2. 点击绿色的 **Code** 按钮，再点 **Download ZIP**。
3. 下载完成后，找到 ZIP 文件，右键点击它，选择 **全部解压**，再点 **解压**。
4. 打开解压后的文件夹，直到能看到 **`setup_ml.cmd`** 和 **`start_tracker.cmd`**。

请在解压后的普通文件夹里操作。电脑可能隐藏文件后缀，此时只显示 `setup_ml` 和 `start_tracker`。

本仓库已公开，下载无需邀请。若链接打不开，先检查网址和网络连接。

## 第 2 步：安装，只做一次

先安装运行工具需要的 Python。如果已经装好了 **Python 3.12 和 Python Launcher（启动器）**，可跳过这一小段。

1. 点击[下载 Python 3.12 的 Windows 安装程序](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe)。
2. 双击下载的文件，勾选 **Add python.exe to PATH**，其他选项保持默认，包括 Python 启动器。
3. 点击 **Install Now**，安装成功后点 **Close**。

下载链接来自 [Python 官方页面](https://www.python.org/downloads/release/python-31210/)，提供带图形安装器的 3.12.10 版本。

然后回到第 1 步解压的工具文件夹：

1. 双击 **`setup_ml.cmd`**。
2. 会出现一个黑色窗口，自动下载所需文件。第一次可能比较久，请保持联网，等待完成。
3. 看到 **`Installation complete. Open start_tracker.cmd to start.`**，就表示安装成功。按键盘任意一个键关闭窗口。

不清楚显卡型号，也可以先按默认步骤安装。没有可用显卡时，程序会使用电脑的处理器运行，训练会慢一些。

## 第 3 步：打开工具

双击 **`start_tracker.cmd`**，稍等，浏览器会自动打开。

看到“**让模型学会识别你的颗粒**”这个标题，就打开成功了。页面运行在你自己的电脑上。

**以后每次使用，只需双击 `start_tracker.cmd`，不用重复安装。**

## 第 4 步：生成第一张圆圈残影图

这一步使用自带示例，**不用先训练，也不用点“识别当前帧”**。

1. 页面顶部的“实验视频”选择 **`sample.mp4`**。
2. 点击 **3 · 识别与追踪**，向下滚动，找到 **时间轨迹与圆圈残影**。
3. “追踪结果来源”选择 **样例 · 传统模板追踪（身份未经真值核验）**。
4. 其他设置先不改，直接点 **生成时间痕迹图**。
5. 图片出现后，点击 **下载 PNG**。图片通常会保存在电脑的“下载”文件夹里。

看到这样的图片，就完成第一次试用了：

| 想做什么 | 怎么操作 |
| --- | --- |
| 只看一颗或几颗 | 取消勾选不想显示的颗粒 |
| 只看某一段时间 | 修改“起始帧”和“结束帧”；帧就是视频中的一张画面 |

## 想处理自己的视频

**当前下载包没有已经训练好的 TEM 颗粒模型。** 第一次需要你给颗粒画框，教会模型后，再让它识别和追踪。

<details>
<summary><b>点击展开：处理自己视频的 5 个步骤</b></summary>

### 1. 放入视频

点击 **添加实验视频**，填写“独立实验组名称”（例如“实验A”），选择视频文件，点 **导入视频**。先用一段较短的 MP4，单个文件不超过 512 MB。同一次实验的片段使用同一个组名。

### 2. 给颗粒画框

进入 **1 · 标注数据**，拖动图片下方的滑块查看不同画面。

按住鼠标左键，拖出一个框，把颗粒包住。已有框可以移动、调整大小或删除。**每张用于训练的画面，都要框出其中所有能辨认的颗粒，包括以后不打算追踪的颗粒。**

检查完一整张画面，点 **整帧已完整标注，确认保存**；没检查完就点 **保存草稿**。身份 ID 可以留空。

从视频前、中、后段各挑几张画面重复操作，不要只标第一张。若用自带样例练习，可选第 **0、4、8、12、16、21、23、25** 帧。这只是起步练习，效果要在训练后检查。

### 3. 让模型学习

第一次先用一段视频练习：

1. 进入 **2 · 训练模型**。
2. “验证方式”选 **单视频试训：时间分块并隔离相邻帧**。
3. 点 **创建数据版本**，等待完成。
4. 在“数据版本”中选刚创建的那一项，其他设置保持默认。
5. 点 **开始训练并验证**，等页面提示“模型已训练”。

提示数据不足时，回去补充视频前段和后段的完整标注。只保存草稿还不能用于训练。单视频试训能帮助跑通流程，但不能保证对新实验同样有效。

### 4. 选择要追踪的颗粒

1. 进入 **3 · 识别与追踪**，选择刚训练完成的模型。
2. 点 **识别当前帧**，等橙色框出现。
3. 点击想追踪的颗粒框，选中后会出现绿色圆圈。
4. 点 **追踪所选颗粒并导出**。

不知道“采集帧率”和“像素尺寸”时，留空即可。

### 5. 保存结果

完成后点 **追踪视频** 或 **坐标 CSV**。视频打开后，可右键选择“视频另存为”；CSV 是可以用 Excel 打开的坐标表。

要生成圆圈残影图，向下找到 **时间轨迹与圆圈残影**，选择刚完成的追踪结果，再按首页第 4 步生成和下载。

以后导入新视频，可以选择同一个模型，直接从“识别当前帧”开始。检查有没有漏掉颗粒、圈错位置或跟错目标；效果不好时，需要补充标注再训练。

## 标注和试训注意事项（先看这里）

### 标注：每一帧分别确认

- **右侧“可留空”不用填。** 它是可选的颗粒身份 ID，不是类别编号；检测训练不需要跨帧 ID。每帧可以标不同的颗粒，数量也可以不同。若填写 ID，必须是正整数，同一帧不能重复。
- **不用逐帧标，但选中的训练帧要标全。** 框住所有符合实验定义、可辨认的颗粒，不只标以后想追踪的几颗。框贴近外缘，避免重复、漏标及把背景或比例尺当成颗粒。
- **“确认保存”只确认当前帧。** 标完并检查一帧，点击“整帧已完整标注，确认保存”，看到“已确认，可用于训练”后再换帧。只在最后一帧点确认，不会确认前面的草稿。
- “保存草稿”用于未完成或有疑问的帧，不进入训练。当前没有忽略不确定区域的功能；无法判断颗粒数量或边界时，先留草稿。不要把未标注或模糊难辨的帧勾成“负样本”。
- 单击框是选中，拖框内部是移动，拖角点是缩放。从已有框内部起拖不会新建框；相邻目标可从框外反向拖动。误操作可以点“撤销修改”。
- “复制上一帧的框”复制的是紧邻上一帧，并替换当前帧已有框；不会自动跟随颗粒移动。逐个调整、删除离开的目标、补上新目标后，才能确认。
- 切帧时未保存修改会尝试存为草稿；关闭或刷新前主动保存。修改已确认标注后需要重新确认。不要在多个页面同时修改同一帧。
- 换视频不用删除旧视频：画面下方“添加实验视频”→ 填实验组 → 选择文件 → 导入。上方下拉框用于切换。目前没有删除整个视频的界面按钮。

### 一两帧能否测试训练？

当前流程必须同时有训练帧和隔离的验证帧，**只有一帧不能创建可训练的数据版本**。单视频模式也不是随机把所有帧分成两组，而是按视频时间划分。

以自带的 **26 帧视频（编号 0–25）**、默认 25% 验证比例和隔离间隔 2 为例：

| 帧号 | 用途 |
| --- | --- |
| 0–16 | 训练 |
| 17–20 | 隔离区，不进入本次训练或验证 |
| 21–25 | 验证 |

因此，只确认第 0、4 帧仍缺验证数据；再确认第 25 帧后可以建立“2 帧训练、1 帧验证”的流程测试。其他长度视频的分界不同，不要照搬帧号。**能运行不等于模型可靠。** 正式评估应使用真实独立实验分组，同一实验的片段不能改名冒充独立实验。

创建数据版本会收集项目内的已确认标注，不仅是当前显示的视频。单视频模式要求只有一个视频有已确认标注。数据版本是固定快照：后续补标、改标或修改分组后，需要创建新版本并重新训练，旧模型不会自动更新。

### 已知限制：极小数据集的短试训可能几乎没有参数更新

**此项已定位，当前版本尚未加入自动修正。** 本地复现中，2 张训练图、batch=4、5 轮训练，每轮只有 1 个批次；训练器默认梯度累积和预热使 5 轮只触发 1 次优化器更新，首次更新时多数参数组的学习率还是 0。不能把“完成 5 轮”理解为已经充分学习，也不能仅凭训练损失变化判断模型有效。

处理顺序：先检查标签是否读入和位置是否正确，再检查实际优化器更新次数、梯度累积、预热和学习率；针对极小数据集调整这些设置，进行训练帧拟合检查，然后补充代表性标注并验证。仅增加轮数或降低置信度都不保证有效。界面目前没有梯度累积和预热的单独设置，不熟悉训练参数时请附任务日志反馈；开发者应先验证实际更新次数再发布模型。

### “识别到 0 个候选”不等于模型没有输出

本地 5 轮测试模型在第 0、4、25 帧的最高检测分数约为 **0.0125**，低于默认检测阈值 **0.10**，因此界面显示 0 个候选。降到 0.01 后每帧会出现数十个框，但其中包含背景和过大的错误框。

必须区分两种门限：

- `config/learning.yaml` 中的 `inference.confidence` 控制检测候选是否出现。
- 界面的“新目标最低检测分”控制已有候选能否被选为追踪目标，**不会降低检测器本身的阈值**。ByteTrack 还有高分、低分及新目标门限，必须保持一致的分数逻辑。

低阈值只适合诊断。一次独立实验使用检测门限 0.01、ByteTrack 低分门限 0.01、高分及新目标门限 0.011，输出了断裂和跳动的轨迹。10 个目标 × 26 帧中仅 48 条有观测（18.5%）；这只是观测覆盖率，**不是追踪准确率**。这些数值只描述该次测试，不是推荐默认值，软件默认配置未被替换。

排查时先查看检测框是否贴住颗粒，再检查身份是否连续。不要因为出现绿色圆圈和黄色线就认为结果正确；缺测保留为空，不用预测位置冒充测量。当前没有随下载包发布可直接用于实验分析的 TEM 训练权重。

### 本次已修复的标注问题

- 单击选中框但不移动，不再误判为编辑，不会因此把已确认标注降为草稿；真正移动或缩放仍需重新确认。
- 输入重复身份 ID 或非法值时立即提示，重复时指出冲突的颗粒，并保留原值。检测训练可以全部留空。

更新工具后，先保存当前工作，再刷新浏览器加载新界面。标注和模型默认只保存在本机，不会因代码推送到 GitHub 而自动备份。采集帧率和 nm/px 未确认时继续留空，不要把视频播放帧率直接作为实验采集帧率。

## 遇到问题怎么办

| 你看到的情况 | 下一步 |
| --- | --- |
| 没找到 `start_tracker.cmd` | 打开解压后的文件夹，再往里面找一层；确认不是仍在 ZIP 压缩包里 |
| 安装出现 `Setup failed` | 截下窗口中的错误文字，发给提供工具的人；这表示安装没有成功 |
| 提示需要 Python 3.12，或找不到 `py` | 回到第 2 步，确认安装了 Python 3.12，并保留了 Python 启动器 |
| “尚无训练完成的颗粒模型” | 初次使用是正常的；先按第 4 步体验样例，处理新视频再展开训练教程 |
| 圆圈互相挡住 | 少选几个颗粒，或把圆圈间隔调大，再生成 |
| 想停止训练 | 点页面下方“停止当前任务”；只关闭网页不会停止训练 |

其他问题：**把“在哪一步、点了哪个按钮、出现什么提示”连同截图发给提供工具的人。** 会使用 GitHub 的测试者也可以[填写测试反馈](https://github.com/virchant085/tem-particle-lab/issues/new?template=test-feedback.yml)。
